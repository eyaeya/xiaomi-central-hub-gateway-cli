# 云端集成审查与实机验收

日期：2026-10-13。本报告记录审查后的实现与实际验证；不把接口应答、设备报告和现场物理观察混为一谈。

## 基线与范围

上游 mijia-api 固定到 `2cc61f2e4ae21d9e3736e450c968bbe53c87ebd1`。开发树审查起点为 `1653a3e`；正式交付迁移到线上 v2.1.1 的 `d64bc6bfa5c975de813d6b17022f77057284ecce` 基线，升级至 v2.2.0，保留既有 learn、trace、规则导入导出、设备替换及保护机制。

完整能力矩阵见 [初始审查](2026-10-13-cloud-capability-audit.md)。本轮补齐批量/全部可读属性、公开 spec 查询、实例缓存、房间关联、中文说明、更新时间、有界设备观察与 Agent 扫码体验。主要设备业务能力已整合，但没有实现上游所有入口：MCP、批量物理 set/action、场景名称/批量便利接口、无 spec 的原始 MIoT 高层入口、磁盘规格缓存、消息业务输出和 HAR 解密工具仍有差异。当前地区/语言固定为中国区与 zh_CN。

## 已修复的关键问题

1. 默认云端来源可能返回旧缓存，造成恢复误判。新增 `--source auto|device|cache`；watch 默认设备直读，写入前的恢复基线强制设备直读。失败不静默降级到缓存。
2. 日志 follow 对认证/协议错误无限重试。现在立即返回这些错误，暂时网络错误有界重试，并支持时长和事件数量上限；异常日志格式经 schema 校验。
3. 登录仅提供 URL，Agent 没有稳定的图片展示与等待流程。增加私有 PNG、到期时间、待扫码复用与有界 complete；续接命令保留账号、网关地址及自定义 session 路径。
4. 固定二维码图片路径可能被聊天界面缓存。实测在有效期内扫描固定路径图提示过期；换用新文件名后，在未改变登录协议的情况下成功。实现为每个待授权会话使用唯一图片路径，同会话复用；这是有实测支持的缓存解释，未取得界面缓存内部证据。
5. 写入前后按名称反复查找可能错配目标。写入流程固定 DID，实例缓存只缓存元数据而不缓存设备状态；小爱指令默认静默。

## 新扫码到中枢的完整链路

使用独立的新授权文件，Agent 展示二维码，用户用米家 App 扫描并确认后，CLI 返回 `authenticated: true`。随后使用该新授权成功查询云端设备，并用新的独立网关 session 自动获取中枢登录码、完成登录和读取规则列表。链路没有要求用户手工提供六位码。

实机目标是支持该 RPC 的路由器集成中枢。结果不能外推到所有独立中枢、路由器或家庭屏；电脑仍需可访问其局域网地址。凭据可失效或撤销，不承诺一次扫码永久免登录。

## 家庭设备覆盖与恢复

- 共发现 37 台设备：30 台在线、7 台离线，全部完成清单与规格/可读路径检查；规格缺失、只读和离线设备分别记录。
- 选择 17 台具有可恢复属性的设备。1 台因写前设备直读失败被阻止，未执行写入。
- 16 台执行临时属性变更并恢复，16 台均通过设备直读确认原值。
- 其中 14 台确认读到了变更值；另外 2 台有接口应答但未读到变更值，因此不计入状态变化验证通过。
- 涉及灯、净化器、指示灯、音量及可恢复设置。门锁、加热、烹饪、洗涤、场景等没有以不可恢复动作冒充覆盖；传感器以读取验收。

这些结论表示 API 与设备报告层面的证据，不表示逐台进行了现场肉眼确认。离线设备及未运行的动作仍未获得实机动作认证。

## 两个方向的联调

**中枢到云端：** 创建 onLoad 到灯输出的测试规则，完成 `validate --spec-aware` 和 `lint --strict` 后启用。云端设备直读 watch 捕获 `false → true → false`，并取得网关执行日志。先停用输出入口，再恢复原值。

**云端到中枢：** 启用只读观察规则，通过云端改变灯状态；中枢设备读取节点写入变量得到 `1`，云端恢复后变量得到 `0`，同时取得对应日志。最终设备回读为原值，两条规则均再次读取确认 `enable: false`，按项目约定保留供用户检查。

## Skill 与交付检查

Skill 已加入云端优先登录、展示二维码、自动取码、明确账号/网关续接、两向联调、来源选择及恢复证据边界。公开源、npm 随包副本与实际安装副本保持同步，保留 v2.1.1 的学习及规则能力。

最终发布以根目录与 Public 发布工作区的完整检查、包隔离安装及实际发布记录为准。新增云端测试使用 fake transport/store；脱敏真实响应与合成协议 fixture 分开标记。私有设备标识、地址、授权、快照、实际日志与原值留在忽略目录，没有进入公开报告或 npm 包。
