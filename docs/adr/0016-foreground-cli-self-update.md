# ADR 0016：前台 CLI 自更新与 registry 回退

- 状态：Accepted
- 日期：2026-10-14
- 发布版本：3.1.0

## 背景

Agent 经常以独立命令调用 xgg，而网关 daemon 可能连续运行很久。把版本检查放进 daemon 会把安装权限、网络访问与网关会话绑在一起；在写操作后更新或重放原命令，还会使设备结果与更新故障混淆。部分用户无法访问 npm 官方源或 GitHub，更新路径需要独立的 registry 回退与明确的来源说明。

## 决策

更新属于 CLI 的本机安装管理能力，不进入 Core SDK，不依赖米家授权、网关连接或 session。`xgg update --check` 只检查；`xgg update` 检查并升级，均输出可解析结果。显式失败返回非零并给出处理指引；离线、镜像滞后与当前来源无新版必须区分。

默认先查询 npm 官方 registry，失败后尝试 npmmirror，元数据获取与暂存安装均可回退。`--registry <https-url>` 优先于 `XGG_UPDATE_REGISTRY`，显式来源须使用 HTTPS，且不会修改 npm 的全局配置。选定稳定版本后固定该版本，验证 CLI/Core 身份、版本与 Node 兼容性，不因备用源落后而降级。镜像是另一个分发信任来源，TLS 与包完整性不能证明其与官方源实时一致；输出和文档不得保证所有大陆网络均可用。

仅管理通过运行入口、真实包路径与 npm global root 一致性确认的 npm 全局安装。源码 checkout、项目局部依赖、npx 缓存、pnpm 链接及不明安装不自动覆盖。不会提权，不会转装到另一个 prefix；其他安装方式保留原包管理器处理入口。

安装在同一文件系统的临时目录中准备完整依赖，npm 子进程使用独立 argv，不启用 shell，禁用 lifecycle scripts、audit 与 fund，并限制超时和输出。新安装先检查包身份及 CLI/Core 配对，再在关闭自动更新的环境中运行 `--version` / `--help`。提升新目录前保留旧目录，失败时恢复，并保存中断后的恢复信息。安装锁防止同时更新同一目标；锁的失效恢复不能仅凭旧 mtime 删除仍在运行的所有者。诊断不原样公开 npm 输出或认证配置。

自动更新只在白名单内的有限前台只读命令中运行，入口为 Commander 命令行解析之后、旧 CLI 业务 action 之前的 preAction。成功检查后 24 小时内不重复，失败后退避 1 小时；这是滚动时间间隔，不是本地午夜定时任务。`XGG_AUTO_UPDATE=0` 关闭自动行为。daemon、登录/扫码、logout、写操作、原始 api、持续 watch/follow、help/version、CI 与源码调用不触发。没有常驻更新进程或定时网络轮询。

自动更新不写业务 stdout，离线等更新失败时由原 CLI 继续查询。安装完成后立即以同一组 argv 启动新 CLI，携带仅用于交接的防递归标记；旧 CLI 的业务 action 不得执行，新 CLI 也不得再次运行自动更新，因此本次业务查询只执行一次。父进程透传新 CLI 的 stdout、stderr 和退出状态，切换成功后才报告已生效；不能将仅完成磁盘安装表述成当前调用已经使用新版本。现有 daemon 保持连接及原版本，Agent 代码随下一次正常登录启动更新，不强制 logout/relogin。

安装变更使用安装专用的暂存、备份、锁与恢复记录，不调用设备 mutation 的 `dumpBeforeWrite` 或网关快照 guard；它不写网关或云端设备。原有设备写前快照契约保持独立。更新随包 Skill，但不覆盖 Agent 全局发现目录中的独立副本；由显式 Skill 安装/同步流程处理，并保留用户定制内容。

## 验证要求

元数据 schema、API 文档、脱敏 fixture 与 contract 测试同时维护。单位测试注入 transport、process runner 与文件系统替身；发布前执行真实 tarball 隔离安装，检查固定版本升级、回退下载、失败恢复、并发锁、节流及 stdout/退出码保持。根目录与 Public 工作区各自运行完整检查，Skill 全树同步后验证内容摘要。

## 代价与边界

白名单查询在业务执行前可能等待一次有界的检查或安装；其他命令不承担这项等待。保留旧版本和暂存完整依赖需要额外磁盘空间。正在运行的 daemon 与 CLI 版本可能短暂不同；这比更新过程中丢失一次性登录会话更符合现有复用契约。registry 镜像只能提高可达机会，不能代替用户网络、可信分发来源和实际安装回读。
