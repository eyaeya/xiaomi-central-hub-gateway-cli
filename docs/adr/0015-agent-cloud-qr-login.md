# ADR 0015：Agent 可展示的云端扫码登录

日期：2026-10-13。状态：accepted。

米家云端登录应让 Agent 展示二维码、引导用户确认，并在有界等待后报告明确状态。
已有实现只返回两个 URL，重复开始会覆盖未过期登录，CLI 的普通请求超时也会截断扫码等待。

在 CLI 包新增 `qrcode` 运行时依赖与 `@types/qrcode` 开发依赖，仅用于把小米返回的
`loginUrl` 在本机编码为 PNG。core 不引入二维码或 CLI 依赖，不从第三方二维码服务
下载图片，也不把登录 URL 发送给其他服务。生成目录权限为 0700、PNG 为 0600，路径
按认证文件隔离；JSON stdout 返回绝对 `qrImagePath`、可展示的 `qrMarkdown` 与扫码说明。
终端和 Agent 都可消费同一结果；不把 ASCII 图案混进 JSON。

未过期 pending 默认复用，`--restart` 才显式重建；坏凭据只有显式 restart 可以重建，
不能由日常设备请求自动删除。普通 HTTP 超时与 `--wait-ms` 分离，扫码等待默认 20 秒、
最多 60 秒；等待超时返回 pending 并保留二维码，真实网络错误仍报错。二维码过期后
应重新开始，不能无期限等待。认证成功或 logout 清理对应 PNG。

网关认证错误优先提示云端授权和显式 `cloud gateway login --did`，手动六位码是兜底。
所有凭据和网关取码仍仅留私有存储/内存，不进入输出、快照或公开文档。
